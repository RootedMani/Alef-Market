## Persian glossary (always use these terms)

| English | Persian |
|---|---|
| support | حمایت |
| resistance | مقاومت |
| level / zone | سطح / ناحیه |
| breakout | شکست |
| volume | حجم معاملات |
| volatility | نوسان |
| stop loss | حد ضرر |
| take profit | حد سود |
| drawdown | افت سرمایه |
| win rate | نرخ برد |
| trade | معامله |
| position | پوزیشن |
| candle | کندل |

Keep tickers (BTC, ETH, USDT) and indicator names (RSI, EMA, SMA, ATR) in English.
Write all numbers with Latin digits (0-9), never Persian digits.
